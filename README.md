repo ini berisi kode latihan dasar pemrograman dart mengenai variabel dan type safety
1. Variabel dan type safety: deklarasi tipe data dasar (`String`, `int`, `double`, `bool`) dan pembuktian bahwa tipe data di Dart tidak bisa diubah secara implisit setelah dideklarasikan
2. Sound Null Safety**:
   non nullable:variabel biasa secara default tidak bisa diberi nilai `null`.
   Nullable (`?`)**:menggunakan tipe data bersimbol `?` agar variabel diizinkan bernilai `null`.
   null aware Operator (`??`): memberi nilai pengganti fallback jika variabel yang dipanggil bernilai `null`.
